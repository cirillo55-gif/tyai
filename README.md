# TYAI: Модульный саморастущий ИИ на языке Rust (формат `.tyai`)

Прототип модульной нейросети с иерархической маршрутизацией, тернарными весами (`-1, 0, 1`), конструктивным авторостом нейронов (нейрогенезом), обрезкой (pruning) и упаковщиком в единый бинарный контейнер `.tyai`.

Работает исключительно на CPU, без матричных умножений с плавающей точкой (`f32`/`f64`), потребляет минимум ОЗУ и использует `mmap` для ленивой подгрузки модулей по требованию.

## 2. Ключевые особенности математического ядра

1. **Тернарные веса (`-1, 0, 1`) без умножений:**
   * Все веса хранятся в типе `i8`.
   * Прямой проход (инференс) реализован исключительно через сложение, вычитание и целочисленную пороговую активацию:
     $$\text{out} = \begin{cases} +1, & \text{если } \sum > \text{threshold} \\ -1, & \text{если } \sum < -\text{threshold} \\ 0, & \text{иначе} \end{cases}$$
2. **Конструктивный нейрогенез и обрезка:**
   * Каждый из 40 мини-ИИ стартует с 10 нейронов.
   * При обучении активируется авторост (нейрогенез) до **512–1024 нейронов** на модуль с тернарными связями.
   * Применяется локальная пластичность синапсов (безградиентная адаптация весов) и параллельное обучение через Rayon на всех доступных ядрах CPU.
   * В конце обучения запускается Pruning (обрезка зануленных и не влияющих на выход нейронов), сохраняя целевой активный ансамбль из 512 нейронов на каждого эксперта.
3. **Безградиентное эволюционное обучение:**
   * Обучение на основе синаптической пластичности тернарных весов и эволюционных мутаций. Тяжелые матрицы градиентов не создаются, обучение 1760+ примеров на 40 экспертах занимает секунды.

## 3. Спецификация формата `.tyai`

Файл модели `model.tyai` представляет собой единый бинарный контейнер со следующей структурой:

* **Header (24 байта):**
  * `magic`: `b"TYAI"`
  * `version`: `u32` (версия 1)
  * `total_modules`: `u32` (общее число упакованных модулей: 40 экспертов + Vocab + Node 1..3 + Router = 45)
  * `index_count`: `u32`
  * `index_offset`: `u64` (смещение до начала Index Table)
* **Index Table:** Массив записей `TyaiIndexEntry { module_id: u32, offset: u64, size: u64 }`
* **Payload:** Сырые сериализованные данные словаря, узлов и тернарных весов экспертов.
* **Ленивая загрузка (`mmap`):** Клиент `tyai_run` мапит файл в адресное пространство и загружает в оперативную память **только** заголовок, словарь, диспетчеры и 1–2 эксперта, выбранных маршрутизатором для конкретного запроса.

## 4. Пошаговая инструкция по сборке и запуску

### Шаг 0: Сборка проекта
```bash
cargo build --release
```

### Шаг 1: Генерация словаря и датасета
Загружает 10 000 базовых слов из `words.txt`, импортирует диалоги из `dialogs.txt` (40 000+ реплик) и формирует `brain_raw/vocab.bin` и `brain_raw/dataset.bin`:
```bash
./target/release/gen_dataset
```

### Шаг 2: Поэтапное обучение
* **Фаза 1:** Обучает 40 экспертов (по 512 нейронов на каждый) на распределенном диалоговом корпусе и сохраняет модули `brain_raw/expert_00.bin` .. `expert_39.bin`.
* **Фаза 2:** Замораживает веса 40 экспертов и обучает иерархическую маршрутизацию (`Node 1`, `Node 2`, `Node 3`, `Main Router`, `Sub-Routers`):
```bash
./target/release/trainer
```

### Шаг 3: Сборка единого бинарного контейнера `.tyai`
Упаковывает все модули из `brain_raw/` в файл `model.tyai`:
```bash
./target/release/packer
```

### Шаг 4: Запуск интерактивного чата в терминале
```bash
./target/release/tyai_run --model model.tyai
```

## 5. Доступные служебные команды в клиенте

В терминальном клиенте `tyai_run` поддерживаются следующие команды:
* `/stats` — выводит сводку по смонтированной модели `.tyai` (версия, размер словаря, суммарное число нейронов во всех 40 экспертах, попадания в кэш и вызовы нейросетей за сессию).
* `/clear` — мгновенно очищает оперативный кэш-буфер диспетчера.
* `/learn <вопрос> | <ответ>` — интерактивное дообучение: пара добавляется в оперативный кэш и дописывается в `dialogs.txt` для будущих тренировочных циклов.
* `exit` / `выход` — завершение работы.
